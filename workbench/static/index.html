Run and compare the capital as power model

Use this page to run the model, see the results as charts and compare runs with different settings.

What this model is, and what it is not

The model is a computer simulation of a theory by Jonathan Nitzan and Shimshon Bichler, called capital as power. The theory says that owning capital is a form of power over society. It says that owners judge this power by comparing themselves with the average, not by how much they produce.

The model is about power relations. It is not built to predict the future or to copy the historical record. Do not read its results as a forecast or as history.

Years in the model are labels counted from a start labelled 1890. They are not real dates.

Every number in the model that the book does not give was added by the people who built the model. The description of each module says which parts are additions.

How to use this page

  1. Under Set up a run, choose how many firms and years to run, and which modules to switch on.
  2. Select Start run. The charts fill in year by year while the model runs.
  3. To see what difference one change makes, start a second run that differs in that one thing. Then tick both runs in the list under Runs and charts.

New words are explained under Words used on this page.

Set up a run

There is a problem

    A name helps you tell runs apart, for example "Hype switched on" or "Mergers twice as fast". You can change it later.

    Number of firms at the start

    The model was built to start with 300,000 firms, which is close to the number of firms in the United States in the 1910s.

    Fewer firms make a run much faster. But with fewer firms, the 100 largest make up a bigger part of the whole, and this changes the results for them. Use a smaller number to try ideas out. Use 300,000 before you rely on a result.

    Enter a whole number between 1,000 and 3,000,000.

    Years are counted from a start labelled 1890. With 119 years the run ends at the year labelled 2009. The labels are not real dates.

    Some rules in the model use chance. The seed is a number that fixes those chances. Two runs with the same seed and the same settings give the same results. Change the seed to see how much a result depends on chance.

    Modules

    A module is one part of the theory written as a rule, for example mergers or resistance. Each module has settings. A setting is a number that controls how strong or how fast its rule is. Every setting starts at its default, the value the model's builders chose.

    Reading the list of modules from the model…

    Type part of its name, for example "debt".

    Use this if the model has been changed since you opened the page. Your choices are kept where they still apply.

    Modules that always run

    These modules are the centre of the model. You cannot switch them off, but you can change their settings. An optional module can run in place of one of them.

    Modules you can switch on

    These modules are off unless you switch them on. Some of them only measure things and change nothing in the model. Their descriptions say so.
